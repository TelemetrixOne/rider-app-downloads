# TelemetrixOne Rider App

Official Android APK downloads. Application source remains private.

[Download the latest Rider App](https://github.com/TelemetrixOne/rider-app-downloads/releases/latest/download/TelemetrixOne-Rider-App.apk)

Install over the existing app. **Do not uninstall or clear app data.** Android 8.0 or later is required. Allow installation from your browser if Android prompts you, open the downloaded APK and choose Install/Update. Existing settings and pairing are retained by an in-place upgrade.

**v3.0.1:** Race readiness opens the first setting that needs correction and explains it in place. Numeric settings show their allowed ranges and have minus and plus controls. See the [release notes](https://github.com/TelemetrixOne/rider-app-downloads/releases/tag/v3.0.1).

**v3.0.0:** Guided setup, a race readiness check, rider message previews, recovery for temporary sign-in and display failures, and configurable sideways-roll confirmation. Use **Calibrate Now** with the phone mounted and the trike upright to use the new sideways-roll calibration. See the [release notes](https://github.com/TelemetrixOne/rider-app-downloads/releases/tag/v3.0.0).

**v2.13.2 audible pit alerts:** open **Pit Message Alerts** in the Android app settings for **Audible Pit Alerts** and **Test Sound**. Alerts default to on. A new pending pit message in Race Mode plays a short chime at maximum media volume and then restores the previous volume. Use Test Sound on a spare phone outside race operation to confirm its audio settings and output. See the [release notes](https://github.com/TelemetrixOne/rider-app-downloads/releases/tag/v2.13.2).

**v2.13.1 restores single-press calibration:** keep the phone mounted and the trike upright and still, then press **Calibrate Now** once. The reference is saved automatically after a short capture; no leaning steps or second capture. Earlier valid saved calibrations are supported. See the [release notes](https://github.com/TelemetrixOne/rider-app-downloads/releases/tag/v2.13.1).

Only audited, non-debuggable, upgrade-compatible builds from v2.11.1 (versionCode 22) onwards are distributed here. Releases include the versioned APK, identical stable-name APK, checksum and release.json.
