# TelemetrixOne Rider App

Official Android APK downloads. Application source remains private.

[Download the latest Rider App](https://github.com/TelemetrixOne/rider-app-downloads/releases/latest/download/TelemetrixOne-Rider-App.apk)

Install over the existing app. **Do not uninstall or clear app data.** Android 8.0 or later is required. Allow installation from your browser if Android prompts you, open the downloaded APK and choose Install/Update. Existing settings and pairing are retained by an in-place upgrade.

**v2.13.1 restores single-press calibration:** keep the phone mounted and the trike upright and still, then press **Calibrate Now** once. The reference is saved automatically after a short capture; no leaning steps or second capture. Earlier valid saved calibrations are supported. See the [release notes](https://github.com/TelemetrixOne/rider-app-downloads/releases/tag/v2.13.1).

Only audited, non-debuggable, upgrade-compatible builds from v2.11.1 (versionCode 22) onwards are distributed here. Releases include the versioned APK, identical stable-name APK, checksum and release.json.
